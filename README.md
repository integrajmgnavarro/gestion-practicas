# Sistema de Gestión de Prácticas Académicas

## Descripción
Aplicación web para la gestión integral de prácticas académicas desarrollada con Java, Spring Boot y MySQL.

## Tecnologías
- Java 11+
- Spring Boot
- Spring MVC
- Spring Security
- MySQL 8.0
- Thymeleaf
- Bootstrap 5
- Maven

## Requisitos
- JDK 11 o superior
- MySQL 8.0
- Maven 3.6+
- Eclipse o Spring Tools Suite
